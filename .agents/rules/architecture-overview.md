# Architecture Overview

Apply this rule at the start of any session that involves adding, changing, or
reviewing code in this repository.

## Rule

Read `.docs/architecture/overview.md` before making any significant code
change.
It documents the system shape: monorepo layout, hexagonal architecture, domain
entities, Next.js app structure, and the design system.

Use it as the primary orientation document when you are unsure where a new file
belongs, which layer owns a concern, or how the pieces fit together.
