# Default shortcut ⌘⇧\

## Context

Recorded as decided in [Open questions](../../../../../../../specs/08-open-questions.md) ("Default hotkey").

## Considered options

- ⌘⇧\
- ⌥Space
- Ctrl+`

## Decision

Chosen option: "⌘⇧\". The recorder in Settings and the onboarding changes it.

## Consequences

- Good: rarely taken by other apps.
- Bad: needs three keys.
