# Tabs in a sidebar on the left by default

## Context

Recorded as decided in [Open questions](../../../../../../../specs/08-open-questions.md) ("Tab side"): left by default, like the Warp screenshot.

## Considered options

- Sidebar on the left
- Sidebar on the right
- Tab bar on top

## Decision

Chosen option: "Sidebar on the left". Right and top stay available with `tabs-position`.

## Consequences

- Good: long folder names and commands fit.
- Bad: the sidebar takes horizontal room on small windows.
