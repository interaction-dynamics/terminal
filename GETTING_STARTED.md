# Getting started

## Deployment on Vercel

To deploy this project on Vercel, follow [Deploy to Vercel](.docs/how-to/deploy-to-vercel.md): it sets up the database, the Vercel project and its environment variables, the domain and the Resend sending domain.

## Initialization of CONTRIBUTING, CODE_OF_CONDUCT, and PULL_REQUEST_TEMPLATE, etc

```bash
# to generate custom contributing guidelines, code of conduct, and pull request template
npx contributing-generator
```
